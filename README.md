# ちゃっとピンマップ 2.4.14

地図画像や紙地図の写真に、ピン・メモ・手描きルートを記録し、Delta Chatのグループで共有するアプリです。防災・避難所・地域の危険箇所調べのほか、食事・医療・観光・イベントのブース案内にも利用できます。

## GPSの任意付加と確認待ち通知

ピン登録画面の「GPS位置情報を付加する（任意）」を選び、「現在の位置を取得」を押すと、緯度・経度・精度・取得日時をピンと一緒に共有します。初期値はオフです。取得するのは端末の現在地であり、地図をタップした場所の座標ではありません。ピン位置の自動配置や連続追跡は行いません。詳細・管理者の承認欄・JSONに保存します。取得を許可されない場合は付加をオフにして登録できます。ルートには付加しません。

管理者ログイン中の確認待ちは、画面上部の通知帯と設定タブの件数で知らせます。「設定」→「管理者設定」→「確認待ちの通知」で音をオンにし、「通知音を試す」を押してください。初期値はオフで、この端末だけに設定を保存します。「確認待ちを開く」から承認欄へ移れます。アプリ終了中のプッシュ通知はありません。

模擬位置情報によるGPS取得・拒否・共有・保存、通知音の呼び出しは検証済みです。実機での測位・発音は未確認で、Delta Chatと端末の対応・利用許可・音量設定等に依存します。詳しくは16章構成の図入りマニュアルをご覧ください。

## 最初に使うとき

1. Delta Chatの通常のグループへxdcをファイルとして送ります。
2. 全員が同じメッセージからアプリを開きます。別々に送ったコピーや新版は別の共有場所です。
3. 管理者を置く場合は代表端末の「設定」で初期パスワード secret を入力し「切り替える」を押します。初期タップ回数は1回です。
4. 管理者設定後に8文字以上の新しいパスワードへ変更します。タップ回数は1〜10回です。
5. 一般端末では、本人から教わった「管理者確認コード」12文字またはQRを読み取り、「この管理者を確認」を押します。「端末確認コード」やパスワードとは別です。
6. 地図を登録し、ピンやルートを追加して、受信側で表示を確かめます。

## 権限と確認

| 役割 | 操作 |
|---|---|
| 一般参加者 | 閲覧・検索・書き出し・新規登録。既存情報の編集・移動・削除・復元は不可 |
| 書き換え権限者 | 編集・移動・削除・復元も可能。権限は管理者が端末ごとに付与 |
| 代表管理者 | 権限管理、登録・変更の確認と配信、管理者設定 |

管理者未設定なら新規登録は即時共有します。設定後は一般参加者と書き換え権限者の登録・変更を管理者が確認して配信します。管理者が閉じている間は確認待ちです。管理者自身の操作は直接配信します。

QRを読んだだけでは管理者確認は完了しません。照合先の管理者情報が未受信だと確認ボタンはグレーになります。同じメッセージを開いているか確認し、代表管理者の「管理者情報を再送」を使ってください。

Androidでカメラが開かない場合は、標準カメラでQRを写真として保存し、アプリの「撮影済み・保存済みのQR画像を読み取る」で選びます。ぼけ・反射を避け、白い余白も含めます。文字入力も利用できます。

代表管理者へのログインは最初に設定した端末だけで行えます。終了後・再起動後は再ログインが必要です。管理者鍵・パスワード・権限設定はJSONに含まれません。鍵の引き継ぎ・紛失時の復旧機能はありません。初期パスワードを変更し、端末を適切に管理してください。

## バックアップと新版への移行

1. 旧アプリでJSONを書き出して保存し、ファイルを確認します。
2. 新版をグループに送り、全員が同じメッセージから開きます。
3. 移行先の代表管理者を設定し、JSONを復元します。JSONは15MB以下です。
4. 復元後はアプリを閉じず、地図とピンを確認し「復元したデータを含む全地図を共有」を押します。復元だけでは他端末へ共有されません。
5. 各端末で新しい管理者コードを確認し、地図・ピン・ルートが揃ってから旧アプリを整理します。

## デモと制約

index.htmlは外部ファイル不要の単体デモです。変更はそのブラウザー内に保存され、他端末へ共有されません。上部のサンプルへ戻す操作で、デモの登録内容と管理者設定をリセットできます。実際の共有はxdcをDelta Chatで使ってください。

地図は長辺1600px以下・約180KB以下に圧縮されます。保存済み地図は通信断でも閲覧できますが、端末間の反映には通信が必要です。位置は手動指定です。GPS追跡、自動経路探索、安全判定、全員の到着・既読確認はありません。「送信待ちなし」は全員への到達保証ではありません。

地図の保管・改名・複製・完全削除、検索・状態・確認日時、画像とJSONの書き出し、再送に対応します。完全削除でも配信済みチャット履歴や書き出したファイルは消せません。災害時の判断は現地の状況と公的情報も合わせて行ってください。

2.4.14の共有・権限・QR・復元・再送・GPS付加・確認待ち通知は模擬端末で検証しています。すべてのAndroid・iPhone・PCでの動作を保証するものではなく、実際に使う端末でも事前に試してください。管理者権限の仕組みは第三者による監査を受けていません。
