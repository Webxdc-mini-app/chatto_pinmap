# ちゃっとピンマップ 2.3.0

地図の写真や画像に、場所を示すピンと手描きのルートを重ねて、Delta Chatのグループで共有するアプリです。防災だけでなく、食事・医療・避難所・観光・危険箇所の点検・イベントのブース案内に使えます。

## 2.3.0の追加

ピン・ルートの編集と移動、確認日時・状態、検索と地図／一覧の絞り込み、地図の改名・保管・複製、全地図の移行共有を追加しました。

[追加機能と移行手順](chatto_pinmap-2.3.0-追加機能と移行手順.md) ／ [画面付き操作ガイド](chatto_pinmap-2.3.0-guide.html)

新版に旧版の情報は自動で移りません。旧版からJSONを保存し、新版で復元後に「復元したデータを含む全地図を共有」を実行します。全員が同じ新版メッセージを開いてください。

## 2.2.4の追加

設定に、画像片の受信数・欠落番号・登録件数の表示と、正常端末からの地図・登録情報の再送を追加しました。実機での原因は未確定です。新版は別の共有場所になるため、[移行と再共有の手順](chatto_pinmap-2.2.4-地図の受信確認と再送.md)をご覧ください。

## 2.2.3の修正

AndroidでJSONボタンを押した直後にDelta Chat自体が終了するとの報告を受け、まずアプリ内の書き出し画面を開く方式に変更しました。「JSONを表示してコピー」から取り出せます。互換ファイル渡しは128 KiB以下に制限しています。実機での終了原因と解消は未確認です。

[Androidの書き出し手順・制限・旧版からの移行](chatto_pinmap-2.2.3-AndroidのJSON書き出し.md)を参照してください。iPhoneはファイル受け渡し、PCブラウザーはダウンロードします。

## はじめるまで

1. 共有したいDelta Chatグループに `chatto_pinmap-2.3.0.xdc` をファイルとして送ります。
2. 参加者全員が、同じチャット内の**同じメッセージのアプリ**を開きます。送り直したコピーは別の共有場所になります。
3. 準備する人が「設定」→「地図の共有」で地図名と画像を指定し、「画像を登録して共有」を押します。
4. 地図の右上で用途を選びます。地図の下のピン項目を押し、場所をタップして登録します。
5. 送信待ちがなくなるまでアプリを開き、ほかの参加者の端末にも反映されたことを確認します。

パソコンでは「タップ」を「クリック」と読み替えてください。詳しい手順と画面図は操作マニュアルをご覧ください。

## 主な機能

- 地図画像の登録・端末内保存・グループへの共有
- 地図ごとの用途設定と、8種類のテンプレート
- ピン・ルートのタイトル・メモ・色・状態・確認日時の登録と編集、移動、削除
- タイトル・メモ・記録者検索、用途・状態・種類・確認日時の絞り込み
- 地図の改名・保管・再表示・複製
- 手描きルートの登録・削除、一覧の用途別絞り込み
- 名前と色を指定するカスタム項目
- JSONのバックアップ書出し・この端末への復元
- 送信待ちの保存と送信再試行

|用途|例|

|防災|避難所・給水・医療・崩落・浸水・火災・要救助|
|食事|ラーメン・カフェ・居酒屋・スイーツ・ランチ・休業注意|
|医療|病院・薬局・AED・支援所|
|避難所|避難所・トイレ・充電・給水|
|観光|絶景・映え・温泉・お土産・駐車場|
|危険箇所|危険・破損・暗い・交通危険・改善済|

どの用途にも「メンバーの位置（手動）」があります。用途・カスタム項目は地図ごとに保存・共有されます。切り替えても既存のピン・ルートは残ります。

## 使う前に知っておくこと

- 完全な通信断では他端末へ即時共有できません。端末内に保存された地図の閲覧・登録は可能です。通信が戻ったらアプリを開き、反映を確認してください。
- 「送信待ちなし」は、この端末で受付待ちのデータがないことを示します。全員への到達や既読を示すものではありません。
- GPSでの自動配置・追跡は行いません。メンバー位置は手動で登録し、移動後は詳細の「移動」で位置を変更します。
- ルートは手描きの参考線です。自動経路検索・通行可否判定・安全性の保証は行いません。
- ピンとルートは参加者全員が編集・移動・削除できます。ルートの移動は形を保った全体移動です。点ごとの形の編集はありません。
- バックアップの復元はこの端末への統合です。復元後に専用の共有ボタンを押すとグループへ送信できます。送信待ちの管理情報はバックアップに含みません。
- カスタム項目自体の名前変更・削除はありません。追加前に項目名を決めてください。

## 画像とデータの目安

|項目|目安・上限|
|---|---|
|元の地図画像|端末で表示できるJPEG・PNGなど。30MB以下|
|登録後の地図画像|長辺1600ピクセル以下・約180KB以下に圧縮|
|ピン・ルートのタイトル|100文字以内、空欄不可|
|メモ|1000文字以内|
|手描きルート|2〜300点|
|カスタム項目名|30文字以内|
|復元用JSON|15MB以下|

PDFや地図タイルは画像へ変換してください。圧縮で文字が読めなくなる場合は、地域や階ごとに分けて登録してください。新しい地図に既存のピンが自動で移ることはありません。

## 困ったとき

- 地図やピンが見えない：同じアプリの同じメッセージ・同じ地図名か確認します。
- ピンが重なって選べない：「一覧」→「詳細・削除」から選びます。
- 送信が進まない：通信状態とチャットの送信権限を確認し、「設定」→「送信を再試行」を押します。
- 保存エラー：端末の空き容量やブラウザーのローカル保存設定を確認します。失敗した登録は取り消され、送信されません。

## 確認状況

ブラウザーの操作デモと模擬webxdc環境で、地図・ピン・ルート・用途・カスタム項目の反映、再起動、重複受信、送信失敗後の再送を確認しています。2026年10月24日、利用者から実際の端末間共有に成功したとの報告がありました。今回追加した画像書き出しとスマホ表示調整は、ブラウザーと模擬APIで検証しています。利用する実機でも表示・保存・共有先選択を確認してください。
