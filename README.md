# ちゃっとピンマップ 2.3.1

地図画像や紙地図の写真に、ピン・メモ・手描きルートを重ねて、Delta Chatのグループで共有するアプリです。災害直後の崩落・浸水・給水所などの記録から、普段のお店・観光・地域点検・イベント案内まで使えます。

利用にはDelta Chatが必要です。保存済み地図は通信がない間も閲覧・記録できますが、他端末への反映には通信が必要です。

## 最初に使うとき

1. 共有するDelta Chatグループへ `chatto_pinmap-2.3.1.xdc` をファイルとして送ります。
2. 全員がその同じメッセージからアプリを開きます。送り直したコピーや旧版は別の共有場所です。
3. 「設定」→「地図の共有」で地図名と画像を指定し、「画像を登録して共有」を押します。
4. 地図の右上で用途を選び、下の項目を押して場所をタップするとピンを登録できます。
5. 送信待ちがなくなるまでアプリを開き、各端末に地図とピンが反映されたことを確認します。

地図が出ない端末では「設定」→「共有の確認・再送」で画像の受信数を見ます。地図が正常に見える端末から、同じ地図の画像・登録情報を再送できます。「送信待ちなし」は全員への到着・既読を示すものではありません。

## 主な機能

- 地図画像の登録と共有、用途別テンプレート8種類、自由な名前と色の項目
- ピンとルートのタイトル・メモ・色・状態・確認日時の登録と編集
- ピンの位置変更、形を保ったルート全体の移動
- タイトル・メモ・記録者の検索、用途・状態・種類・確認日時の絞り込み
- 地図の改名・保管・再表示・複製・完全削除
- 地図JPEG、ピン・ルート付きPNG、JSONバックアップの書き出し
- JSON復元後の全地図共有、画像の受信状況表示と再送

|用途|ピンの例|
|---|---|
|防災|避難所・給水・医療・崩落・浸水・火災・要救助|
|食事|ラーメン・カフェ・居酒屋・スイーツ・ランチ|
|医療|病院・薬局・AED・支援所|
|避難所|避難所・トイレ・充電・給水|
|観光|絶景・映え・温泉・お土産・駐車場|
|危険箇所|危険・破損・暗い・交通危険・改善済|
|イベント|ステージ・ブース・フード・トイレ・救護・案内所|
|カスタム|自由な名前・色の項目|

どの用途にも「メンバーの位置（手動）」があります。用途は地図ごとに共有され、切り替えても既存のピン・ルートは残ります。

## 地図の保管と完全削除

「設定」→「地図管理」で対象を選びます。

- 保管：通常の地図選択欄から隠します。内容は残り、管理欄から再表示できます。保存容量は減りません。
- 完全削除：「この地図を完全削除して共有」を押し、表示された地図名を入力して確定します。画像・ピン・ルート・用途などを削除して共有します。取り消せません。

削除記録を保持し、古い更新やJSONで同じ地図が復活するのを防ぎます。再登録する場合は画像を新しい地図として登録します。Delta Chatの配信済み履歴、旧版のアプリ、書き出した画像・JSONは消去できません。全員が削除でき、削除情報が届くには通信が必要です。

## 旧版から移行する

1. 地図が正常に見えるPCの旧版でJSONを保存します。旧版のメッセージは残してください。
2. グループへ2.3.1のxdcを送り、全員がその同じ新しいメッセージを開きます。
3. PCで新版の「バックアップを復元」からJSONを読み込みます。この段階ではその端末だけへの統合です。
4. 画像が揃っていることを確認し、「復元したデータを含む全地図を共有」を押します。
5. 各端末に地図と登録情報が揃ったことを確認します。旧版への追加・削除は新版へ自動で移りません。

2.3.1から出力したJSONの読み込み先にも2.3.1を使ってください。送信待ちの管理情報はバックアップに含みません。

## AndroidのJSON書き出し

最初にアプリ内の書き出し画面を開きます。「JSONを表示してコピー」→「JSONをすべて選択」→長押しでコピーし、テキスト保存アプリに貼り付けてUTF-8の .json として保存できます。コピーだけでは保存完了ではありません。

互換ファイル渡しは128 KiB以下です。大きいバックアップにはPCからの書き出しを使ってください。これはAndroidでDelta Chatが終了した報告への回避方式です。実機での終了解消は未確認です。

## 制限と目安

|項目|制限・目安|
|---|---|
|元の地図画像|端末で表示できるJPEG・PNGなど、30 MiB以下|
|登録後の画像|長辺1600px以下、約180 KB以下に圧縮|
|タイトル・メモ|タイトル100文字以内で必須、メモ1000文字以内|
|ルート|2〜300点。点ごとの形の編集はありません|
|カスタム項目名|30文字以内。項目自体の改名・削除はありません|
|復元JSON|15 MiB以下|

PDFや地図タイルは先に画像へ変換します。背景画像の差し替えはありません。新しい画像には新しい地図を登録してください。

GPS自動追跡、自動経路検索、通行可否や安全性の自動判定はありません。日時・状態・名前は参加者が記録する情報です。全員が編集・移動・削除できます。確認日時は端末の時計に依存します。

## 確認状況

模擬端末間で、地図・ピン・ルート・用途の共有、編集・移動・確認日時、検索、保管・複製、JSON移行、画像欠落の再送回復、完全削除と古いデータからの復活防止を確認しています。利用者から実機での共有・3台目への再共有の成功報告があります。2.3.1の完全削除とAndroidのファイル受け渡しは、この環境で実機検証したものではありません。

配布物のバージョンは2.3.1です。`chatto-pinmap` はアプリのソースです。通常はxdcを使い、練習には単体HTMLデモを使ってください。
